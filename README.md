# 🚗 Simple Car Showroom 

A pure frontend web layout that serves as a digital car showroom, complete with styling and image galleries. 

## 🎯 Overview
This project was built to practice web structure, styling, and multi-page layouts. It is a completely frontend-focused project. 
It utilizes HTML Frames to manage navigation between different pages, and all styling is handled via internal CSS to keep the showroom looking clean and organized.

## 🚀 Tech Stack
* **HTML:** Used for the core structure, text, inserting car images, and building the frames.
* **CSS:** Used for designing the layout, adjusting visuals, and styling the pages (embedded directly within the HTML files).

## ✨ Features
* Multi-page navigation handled entirely through HTML frames.
* Custom styling and layout using internal CSS.
* Image gallery displaying various car pictures.
* Pure frontend execution with zero backend dependencies.

## 🛠️ How to Run Locally
1. Download or clone this repository.
2. Open the project folder on your computer.
3. Double-click the main `index.html` file to open the showroom in your default web browser. The frames will automatically load the navigation, styles, and image files.
